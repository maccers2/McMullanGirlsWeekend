# McMullanGirlsWeekend

A mobile-friendly guide to our Mothers & Daughters Weekend Away, 17–18 October 2026.

Includes Saturday and Sunday itineraries, venue and taxi contacts, maps and directions, with a plum, pink and gold sparkling design.

## Deploy on Netlify

Connect this repository, select the main branch and leave the build command empty. The publish directory is `.` (configured in netlify.toml).

This is a static web app. No dependencies or build step are required. Map embeds need an internet connection. Train times were supplied by the organiser; venue and taxi contacts were checked on 11 October 2026.

Netlify local linking state is excluded via `.gitignore`.
